# Sealed answers. Stop here first.

Open a file in this folder only when all of these are true:

1. You've made **two honest attempts** at the step.
2. You've read **all three hints** for it in `flight/HINTS.md`.
3. You've asked the local tutor (see `HINTS.md`, top section) and you're still stuck.

If you open one:

- Read it, close it, then **type your own version from a blank file**. Don't copy-paste.
- Write `ASSISTED` next to that block in `flight-log.md`.
- An assisted block isn't done. Rewrite it from blank within 48 hours of landing. That rewrite is the real gate.

These answers are deliberately plain: `for` loops instead of shortcuts, comments that explain why. Yours can look different and still be right. If your version passes `uv run flight/check.py <block>` and you can explain every line, it's right.

Run any answer from the `ai-builds` folder, e.g. `uv run flight/answers/block3_pricing.py`.
